# Michael Jackson — Tribute Page

A single-page React tribute site for the King of Pop. Built with Vite + React, featuring a hero banner, a bio section, and a gallery of his most iconic songs.

**Live site:** [mj-pop-king.vercel.app](https://mj-pop-king.vercel.app)

## Features

- **Hero section** — full-width banner with title and "King of Pop" eyebrow tag
- **The Legend** — a short bio covering his career, record sales, and cultural impact
- **Iconic Songs** — a responsive grid of 12 classic tracks (Billie Jean, Thriller, Bad, Smooth Criminal, and more), each with cover art, title, album, and year
- **Sticky nav** — quick links to Home, About, and Music sections

## Tech Stack

- [React 19](https://react.dev/)
- [Vite](https://vitejs.dev/)
- ESLint for linting

## Getting Started

\`\`\`bash
# install dependencies
npm install

# run the dev server
npm run dev

# build for production
npm run build

# preview the production build
npm run preview
\`\`\`
